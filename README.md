# 📚 ReadLog

> 记录重要论文与协议的阅读过程与笔记，持续维护中。

本仓库用于沉淀我读过的重要论文、协议、阅读笔记与思考。**每篇论文或协议一个独立文件夹**，文件夹内统一存放原文 PDF、阅读笔记和笔记用图。

---

## 🧭 仓库结构

每篇论文或协议对应一个文件夹，命名格式为 `短标题/`，内部结构固定为：

- `paper.pdf`：原文 PDF
- `note.md`：阅读笔记
- `assets/`：笔记中引用的图片
